# Lost Context

### Community Intelligence Platform

Lost Context helps communities understand announcements by showing what changed, preserving previous versions, and highlighting information that needs clarification.

## The Problem

Community announcements can change, and people may miss important updates or misunderstand the latest information.

## Our Solution

Lost Context organizes announcements and helps users review changes, preserve previous versions, and clarify missing information.

## Features

- Create announcements — share community updates.
- Edit announcements — update existing information.
- Version history — preserve previous announcement text.
- Smart change detection — identify added and removed words.
- Clarification questions — ask questions about unclear information.
- Confirmation status — mark announcements as confirmed.
- Browser storage — retain announcements after refreshing the page in the same browser.

## Built With

- React
- TypeScript
- Vite
- CSS

## Run Locally

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Current Limitations

- Announcements are saved in the browser's local storage.
- Data is not automatically shared between users or devices.
- Change detection compares words and may not understand their meaning.

## Project Status

Lost Context is a working prototype designed to help communities understand what changed, what is confirmed, and what still needs clarification.
